# Flappy Ascent

**Flappy Ascent** (ou *Floppy Ascent*) est un jeu vidéo de type "endless runner" développé en Python à l'aide de la bibliothèque **Pygame**. 

Ce projet a été réalisé en groupe de 5 étudiants lors de notre première année de licence (L1) dans le cadre du **CMI (Cursus Master en Ingénierie)** à l'**Université de Montpellier**.

## 🎮 Le Concept du Jeu

Le principe est simple : vous contrôlez un oiseau et vous devez monter le plus haut possible en évitant les différents obstacles générés de manière procédurale (essentiellement des piques sur les murs latéraux). 
Plus vous montez haut, plus votre score augmente. Si vous touchez un pique ou si vous tombez au sol, la partie est terminée ! Arriverez-vous assez haut pour croiser le vaisseau spatial ? 🚀

## 🕹️ Contrôles

* **ESPACE (Spacebar)** : Faire sauter l'oiseau.

## 🛠️ Prérequis et Installation

Pour pouvoir jouer au jeu sur votre machine, vous devez avoir **Python 3** installé ainsi que la bibliothèque **Pygame**.

1. Installer Pygame (si ce n'est pas déjà fait) :
   ```bash
   pip install pygame
   ```

2. Cloner ou télécharger ce dépôt.

3. Lancer le jeu depuis le dossier racine :
   ```bash
   python Main.py
   ```
   *(ou `python3 Main.py` selon votre OS).*
